# 生來瞎眼的人

以約翰福音 9:1–41 為範圍，透過對話、探索、證詞對照與衝突呈現經文的獨立敘事遊戲。

- Story ID：`john-9-man-born-blind`
- 經文：原始 1919 繁體中文和合本（神版）
- 語言：`zh-Hant`
- Scripture artifact：Scrollmapper ChiUn
  `e1b254cef86d0e65b1a5d1a94b8b112d0f296a2c`，John 9 本地成品
  SHA-256 `9d3f8ef447849c9545df32ca2ef78a88de91762e148203316d2505916079a814`
- Foundation：`6c836d55bfd75b55520f13ddab86b9337b5a3c57`
- SDK：`0.3.0`
- 玩家：不介入經文事件的無名觀察者
- 狀態：可遊玩的個人使用候選版本；未宣告 Promotion，仍待 repository owner
  完成經文、敘事與敏感用語審查

## 本地執行

```sh
npm install
npm run dev
```

正式檢查使用 `npm test` 與 `npm run build`。遊戲支援鍵盤、指標與觸控，
並保留正常播放、跳過、重新開始及繼續遊戲的等價最終狀態。音效目前刻意
保持靜音，不使用未核准的 TTS。
