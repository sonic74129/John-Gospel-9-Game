# World 内容

本目录只放当前故事地图契约。当前空间范围只覆盖约翰福音 9:1-7：

- `courtyard`：背景图中央偏右的开放石板区；开场群像以 `courtyard.man-center`
  为视觉与视线汇聚点。
- `siloam-pool`：由一条短而半径校验过的 `man-to-pool` 路线抵达的洗眼地点。
- 9:8-41 的后续区域、NPC 路径和空间触发不属于本地图契约。

- layout
- anchors
- collisions
- navigation
- spawns
- occlusion
- map sequence final states

`framing.json` 同时锁定桌面 1280×720 与 390×844 的开场、洗眼安全取景。
